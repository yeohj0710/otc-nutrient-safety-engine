# 최종 연구 자료

최종 수집 자료는 문헌-질문 조합 **80,965행**이며 유지 판정은 **20,821행**이다. R20260905 사후 검토 10,376행을 반영해 기존 판정 3,703행을 정정하고, 수집 오류로 복원한 1,561행을 처음 선별했다.

현재 논문과 사이트는 정정 후 같은 자료를 사용한다. `research/final/manifest.json`이 정본 명세다. 정정 전 79,404행과 표본 2,505행의 맹검 평가는 과거 분석으로 구분한다.

43,207행의 v5.0 자료는 `research_v3/otc/literature/v5/`에 보존했다. `research_v2/`와 `research_v51/`에는 현행 빌드 의존성이 있다. 과거 경로를 임의로 삭제하거나 이름을 바꾸지 않는다.
