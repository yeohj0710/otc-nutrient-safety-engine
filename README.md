# 권혁찬 연구

국내 일반의약품 안전성 조회. 최종 수집 자료는 문헌-질문 조합 **80,965행**이며 유지 판정은 **20,821행**이다. R20260905 사후 검토 10,376행을 반영해 기존 판정 3,703행을 정정하고, 수집 오류로 복원한 1,561행을 처음 선별했다.

## 최종 자료

- `research/final/manifest.json`: 입력·산출물·코드의 해시와 최종 결과.
- `../evidence-recollect/data/kwon/final/`: 정정한 문헌 자료, 사후 기준, 검토 기록, 최종 판정과 집계.
- `src/generated/recollect/`: 현재 사이트 자료.

제목만 있는 문헌은 사후 기준으로 검토했다. 기존 설명 연결 10건의 인용·요약·적합성을 확인하고 8건을 정정했다. 전체 문헌 후보와 직접 검토한 설명 연결을 구분한다. 허가원문 규칙의 권한과 제품별 지원 범위는 문헌 수와 무관하다.

철회된 논문과 철회 공지는 수집 기록에 보존한다. 공개 화면에는 철회 상태와 서지정보만 표시하며 결과 인용과 AI 요약에는 사용하지 않는다.

## 재현 검사

상담 설명은 `gpt-5.6-luna`, 추론 수준 `max`로 작성한다. 서버가 선택 제품과 입력한 복용량·환자 조건으로 판정을 재현한 뒤, 제품별 허가문과 검토한 문헌을 함께 전달한다. 연구 대상·구체적인 결과·환자와의 차이를 설명하고 출처를 연결한다. 배경 문헌을 직접 근거로 바꾸거나 논문으로 허가 판정을 바꾸지 않는다. 문헌이 없는 항목은 확인된 허가 범위와 확인할 수 없는 내용을 구분한다.

AI 설명은 비동기로 추가되며 최대 4분을 기다린다. 같은 제품·복용량·환자 조건·근거의 설명은 서버 메모리에서 5분간 재사용한다.

문헌은 판정마다 다섯 상태로 나눈다. 직접 일치, 입력 정보 부족(나이나 복용약이 비어 대조하지 못함), 연구 대상과 차이(입력값이 연구 대상과 다름), 추가 선별 후보, 관련 문헌 없음이다. 입력 부족과 대상 차이는 문헌을 숨기지 않고 이유를 붙여 배경으로 보여주며 직접 근거로 올리지 않는다. 검토를 마친 문헌(v5.0 채택 10건)이 없는 규칙과 허가 복용 조건에는 재수집 트랙 선별 통과 문헌 가운데 에이전트가 초록을 읽고 고른 추가 선별 후보를 붙인다. 후보의 출처는 `research/counseling/curated-candidates.json`이고 `python scripts/build-counseling-candidates.py`가 인용 문장을 저장 초록(`research/counseling/sources.json.gz`, `scripts/build-counseling-sources.py`)과 대조해 `src/generated/otc-counseling-candidates.json`을 만든다. 후보는 사람 전문가 검토와 규칙 승인을 거치지 않았고 판정을 바꾸지 않는다.

```powershell
npm run validate:research
npm run validate:literature
npm run typecheck
npm run lint
npm test
npm run build
```

검사는 저장된 자료를 대조하고 결과를 다시 계산한다. 모델이나 유료 API를 호출하지 않는다. 문헌을 새로 읽는 대량 작업은 gpt-5.6-luna를 사용한다.

## 과거 평가와 보존 기록

정정 전 AI 비교는 76,899행의 표본 추출틀에서 2,505행을 채점한 결과이며 일치도는 84.21%다. 원래 판정·표본·채점·잠금 파일을 바꾸지 않았다. 사후 정정 지표와 과거 맹검 지표를 섞지 않는다. 두 AI의 기준 적용 차이도 있어 이 값을 최종 자료의 정확도나 임상적 정확도로 읽지 않는다.

과거 버전 폴더는 감사와 빌드 의존성을 위한 보존 경로다. 현재 자료를 고르는 기준은 이 안내와 최종 명세다. 공개 주소는 https://otc-nutrient-safety-engine.vercel.app 이며 배포 기록은 별도로 확인한다.
