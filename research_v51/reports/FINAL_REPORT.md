# v5.1 일반의약품 안전 확장 최종 보고서

## 결론

v5.1은 v5.0 제출 정본을 바꾸지 않고, 기존 released 규칙 15개의 실행 범위를 제품·성분·입력
조건 단위로 제한했다. 새 후보 규칙은 활성화하지 않았다. 허가 사용·복용 조건 32건은
`ADMIN-*` 판정으로 분리했고, 학술문헌에는 규칙을 release할 권한을 부여하지 않았다.

현재 상태는 `release_ready=false`다. 이 결과는 연구용 시제품의 결정론적 동작과 근거 계보를
검증한 것이며, 임상 정확도나 의료기기 수준의 안전성을 증명하지 않는다.

## 후보 345건은 운영 판정에서 제외했다

허가문구 후보–규칙 연결 360건을 고유 원문 위치 328곳으로 정리했다. 360건은 논문 수나
검증 완료 근거 수가 아니다.

- 기존 운영 근거 15건: `verified_primary`이며 기존 released 규칙에만 연결된다.
- 전문가 검토 큐 33건: `needs_expert_review`다. 검토자의 채택·수정·기각, ID, 역할과 시각은
  모두 비어 있다.
- provisional 308건: 원문 후보는 보존하지만 정확한 실행 조건과 사람 승인이 없다.
- rejected 4건: 분석 제외 제품에 속하므로 운영 판정에 사용할 수 없다.

후보–규칙 연결 360건 중 355건은 보관 식약처 문서의 변경 이력에서 개정일을 확인했다. 변경
이력에 개정일이 공개되지 않은 5건은 `not_reported_in_archived_mfds_change_history` 상태와
사유를 기록했다. 전문가 패킷 33건은 제품·성분, 문서 유형·개정일·UTC 접근일, 확장한 공식
원문 위치와 완결 문맥, 정상·경계·비대상·오탐 방지 회귀 시나리오를 모두 포함한다.

33건 의미 검토에서는 직접 동일 범위 3건, 잠재적 제품 확장 16건, 다른 범위 9건, 중복 맥락
5건으로 분류했다. 검토 권고는 추가 검토 17건, provisional 2건, 기각 14건이지만 이 권고는
사람 승인이나 활성화가 아니다. 임신 시기 2건은 현재 trimester 입력으로 허가문구의 월·주
경계를 재현할 수 없고, 긴급 증상 1건은 전문가가 증상 조합과 중증도를 정하기 전에는 단일
증상 trigger를 만들 수 없어 문구를 보수적으로 고쳤다.

상세 데이터는 다음 파일에 있다.

- `research_v51/evidence/evidence_units.csv`
- `research_v51/evidence/evidence_rule_links.csv`
- `research_v51/review/shortlist_semantic_triage.csv`
- `research_v51/review/expert_review_queue.csv`
- `research_v51/review/expert_review_packet.md`

## 전문가가 결정해야 할 항목이 33건 남았다

전문가는 각 후보에서 완결된 공식 원문과 위치, 제품·성분 범위, 문서 버전·개정일·접근일,
실행 조건, 사용자 문구와 구체적 필수 회귀 테스트를 검토해야 한다. 채택하려면 안정적인 rule
ID, source version, locator, 명시적 승인 기록과 정상·경계·비대상·오탐 방지 테스트가 모두
필요하다. 현재 패킷은 결정란을 비워 두었으며, 패킷 생성기가 검토 완료나 활성화를 자동으로
기록하지 않는다. 두 패킷 출력 중 하나를 게시한 뒤 실패해도 동시 작성자의 파일을 자동
rollback하거나 삭제하지 않는다.
