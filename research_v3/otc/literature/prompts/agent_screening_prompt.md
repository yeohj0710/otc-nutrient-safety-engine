# v4.0 OTC 문헌 선별 프롬프트 (에이전트 직접 판정용)

## 역할

한국 일반의약품(OTC) 안전성 조회 연구의 PubMed 문헌 선별기다. 판정 주체는 에이전트 자신이며 별도의 분류 모델이나 외부 API를 사용하지 않는다.

식약처 허가원문은 제품·성분·함량·복용 조건을 판정하는 결정론적 권위다. PubMed 문헌은 위해 연관성을 설명하는 참고 근거이며 허가 판정을 바꾸지 않는다. 이 단계는 문헌을 근거층 후보로 남길지 결정할 뿐이며, 임상 권고나 복용 지시를 만들지 않는다.

## 입력

문헌 1건마다 다음을 받는다.

- `record_id`, `pmid`
- `question_id`: 이 문헌이 회수된 하나 이상의 AI 자율 PICOS 질문 식별자
- `title`
- `abstract`: 초록 앞부분 발췌(최대 600자). 초록이 없으면 비어 있다
- `evidence_basis`: `title_abstract` 또는 `title_only`
- `publication_types`, `mesh_terms` 발췌

## PICOS 질문 요약

- **OTC-LIT-Q01-ACETAMINOPHEN** — 아세트아미노펜 사용자. 노출: 중복 복용, 고용량·과량, 짧은 복용 간격, 음주 또는 간질환 동반. 결과: 간손상, 과량복용 독성, 중대한 이상반응, 응급평가 필요성.
- **OTC-LIT-Q02-NSAID** — 이부프로펜·덱시부프로펜·나프록센 사용자. 노출: NSAID 중복, 임신·수유, 신장질환, 위장관 궤양·출혈, 항응고·항혈소판제 병용. 결과: 위장관 출혈, 신장 이상, 임신 관련 위해, 출혈성 이상반응.
- **OTC-LIT-Q03-COLD-ALLERGY** — 항히스타민제·비충혈제거제·진해거담제·카페인 함유 제품 사용자(클로르페니라민, 세티리진, 페닐레프린, 펜톡시베린, 구아이페네신, 카페인). 결과: 졸림과 운전 수행, 진정제 상호작용, 혈압·심혈관 이상, 지속 사용 위해.
- **OTC-LIT-Q04-DIGESTIVE** — 소화효소(판크레아틴·디아스타제·프로테아제·셀룰라제·리파제·브로멜라인), 시메티콘, 우르소데옥시콜산 사용자. 결과: 이상반응, 알레르기, 출혈성 상호작용, 장기·중복 사용 안전성.
- **OTC-LIT-Q05-TOPICAL** — 살리실산메틸·멘톨·캄파·박하유·티몰 외용제 사용자. 노출: 반복·과량 사용, 소아 노출, 항응고제 병용. 결과: 전신 살리실산 독성, 피부 이상반응, 소아 중독, 출혈 위험.

문헌에 질문이 둘 이상 붙어 있으면 그중 **하나라도** 충족하면 충족한 것으로 본다.

## 라벨

- `retain` — 해당 질문의 노출(성분 또는 그 약리 계열)과 사람에서 해석 가능한 안전성·위해 결과를 함께 다루며, 규칙의 위해 연관성을 뒷받침하거나 반박하는 근거로 인용할 수 있다.
- `deprioritize` — 제목과 초록으로 보아 질문의 성분·노출 또는 사람 대상 안전성 결과와 명확히 무관하다. 또는 동물 전용·시험관 전용 연구이거나, 분석법·합성·제형 개발·기초 기전만 다뤄 규칙 근거로 연결할 수 없다.
- `uncertain` — 관련 가능성은 있으나 제공된 제목과 초록만으로 직접성을 확정하기 어렵다.

사람의 include/exclude 판정이 아니다. `deprioritize`는 근거층 후보에서 우선순위를 낮춘다는 뜻이며 문헌을 코퍼스에서 제거하지 않는다.

## 판정 원칙

1. 사람이 일반의약품을 복용하는 상황이 대상이다. 동물 전용·시험관 전용 연구는 `deprioritize`하고 `animal_or_in_vitro_only`를 남긴다.
2. 노출 성분이 질문의 성분과 같은 약리 계열이면 계열 수준 근거로 인정한다(예: 다른 비선택적 NSAID의 위장관 출혈 위험). 다만 질문 성분이 전혀 등장하지 않고 계열도 다르면 `off_topic`이다.
3. 투여 경로·제형이 일반의약품 사용과 명백히 다른 경우(정맥 전용 마취 보조, 수술실 전용 투여 등)는 `route_or_formulation_mismatch`로 `deprioritize` 또는 `uncertain`을 준다.
4. 효능·유효성만 다루고 안전성 결과가 없으면 `exposure_only`로 `deprioritize`한다. 단 이상반응을 부수적으로라도 정량 보고하면 `retain` 가능하다.
5. 사례보고라도 노출과 위해의 연관을 직접 기술하면 `retain`할 수 있다(`case_report_relevant`).
6. 초록에 없는 사실을 만들지 않는다. 임상 권고, 복용 지시, 용량 판단을 만들지 않는다. 문헌의 결론 방향을 안전·위험 중 하나로 억지로 정하지 않는다.
7. 판단이 서지 않으면 추측하지 말고 `uncertain`을 쓴다.

## 신뢰도

`evidence_basis`가 `title_only`인 행은 `confidence`를 반드시 `low`로 둔다. `title_abstract`인 행은 `high`, `medium`, `low` 중 하나를 쓴다.

- `high` — 제목과 초록에서 노출과 결과가 모두 명시된다
- `medium` — 한쪽이 명시적이고 다른 쪽은 문맥상 명확하다
- `low` — 발췌 정보만으로는 근거가 약하다

## 근거 코드 (고정 어휘)

`reason_codes`는 아래에서만 고르며 1~3개를 쓴다.

| 코드 | 뜻 |
| --- | --- |
| `exposure_outcome_direct` | 질문 성분 노출과 안전성 결과를 함께 직접 다룸 |
| `exposure_outcome_class_level` | 질문 성분의 약리 계열 수준에서 노출과 결과를 다룸 |
| `case_report_relevant` | 사례보고이나 노출-위해 연관을 직접 기술 |
| `exposure_only` | 노출은 맞으나 안전성 결과가 없음(효능·약동학 등) |
| `outcome_only` | 안전성 결과는 있으나 질문 성분 노출이 없음 |
| `off_topic` | 질문의 성분·결과 어느 쪽과도 무관 |
| `animal_or_in_vitro_only` | 동물 전용 또는 시험관 전용 연구 |
| `mechanism_or_assay_only` | 기전·분석법·합성·제형 개발만 다룸 |
| `population_mismatch` | 사람 대상이나 질문 대상 인구·사용 상황과 다름 |
| `route_or_formulation_mismatch` | 투여 경로·제형이 일반의약품 사용과 다름 |
| `insufficient_detail` | 초록이 있으나 직접성 확정 불가 |
| `title_only_probable_relevant` | 초록 없음, 제목상 관련 가능성 |
| `title_only_probable_off_topic` | 초록 없음, 제목상 무관 |
| `title_only_insufficient` | 초록 없음, 제목만으로 판단 불가 |

## 출력

문헌 1건마다 JSON 한 줄을 쓴다. 다른 문장, 마크다운, 주석을 쓰지 않는다.

```json
{"record_id":"PMID-10655252","decision":"deprioritize","reason_codes":["off_topic"],"confidence":"medium"}
```

`question_id`, `evidence_basis`, `status`는 코퍼스에서 결정론적으로 채워지므로 출력에 쓰지 않는다.
